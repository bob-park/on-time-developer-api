# Documentation

> Where API specs, domain docs, superpowers artifacts live. Read when adding docs.

- API specs (OpenAPI 3) live in `docs/apis/`.
- Domain docs live in `docs/domain/`, including a `glossary.md` (한국어 용어집 OK) and entity relationship diagrams in **Mermaid** (renders on GitHub).
- Superpowers skill artifacts live in `docs/superpowers/`: design specs under `specs/` (filename `YYYY-MM-DD-<topic>-design.md`) and implementation plans under `plans/` (filename `YYYY-MM-DD-<topic>.md`).
